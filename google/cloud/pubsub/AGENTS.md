# Agent Guidelines for Cloud Pub/Sub (`google/cloud/pubsub/`)

Cloud Pub/Sub is a **hybrid** library combining hand-crafted, high-throughput
`Publisher` and `Subscriber` pipelines with generated admin clients, schema
clients, and low-level gRPC stubs.

## Generated vs. Hand-Crafted Boundaries

- **Generated (`DO NOT EDIT`):**
  1. **`pubsub/admin/*`:** `TopicAdminClient` and `SubscriptionAdminClient` in
     `namespace google::cloud::pubsub_admin` (mocks in `pubsub_admin_mocks`),
     generated from `google/pubsub/v1/pubsub.proto` via `service_name_mapping`.
  1. **`SchemaServiceClient` in `pubsub/` root:** `schema_client.{h,cc}`,
     `schema_connection*.{h,cc}`, `schema_options.h`,
     `mocks/mock_schema_connection.h`, and `internal/schema_*` in
     `namespace google::cloud::pubsub` / `pubsub_mocks`.
  1. **Data-plane gRPC stubs in `internal/`:** The 12 files for
     `publisher_*` and `subscriber_*` (`stub`, `auth_decorator`,
     `logging_decorator`, `metadata_decorator`, `round_robin_decorator`, and
     `tracing_stub` `.{h,cc}`).
- **Hand-Crafted:** `Publisher`, `BlockingPublisher`, `Subscriber`, `Message`,
  `AckHandler`, `ExactlyOnceAckHandler`, and all batching, flow-control,
  ordering-key, lease-management, and message-tracing classes in `pubsub/`,
  `pubsub/internal/`, `pubsub/mocks/`, `pubsub/testing/`, and
  `pubsub/integration_tests/`.

## Deprecated Legacy Admin Clients

- Top-level `pubsub::TopicAdminClient` (`topic_admin_client.h`) and
  `pubsub::SubscriptionAdminClient` (`subscription_admin_client.h`) — along with
  `mocks/mock_{topic,subscription}_admin_connection.h` — are **deprecated**
  (`GOOGLE_CLOUD_CPP_PUBSUB_ADMIN_API_DEPRECATED` in `pubsub/version.h`,
  scheduled for removal in v4.x per `doc/deprecated.md`, despite legacy
  references in `ARCHITECTURE.md`).
- Direct all new admin features and samples to `pubsub_admin::TopicAdminClient`
  and `pubsub_admin::SubscriptionAdminClient` under `pubsub/admin/`. Tests that
  exercise the legacy classes must include
  `"google/cloud/internal/disable_deprecation_warnings.inc"`.

## Concurrency, Ordering, and Session Invariants

- **Publishing Pipeline (`Publisher` -> `PublisherConnection`):**
  - `Publisher::Publish(Message)` is asynchronous and returns
    `future<StatusOr<std::string>>`. `BlockingPublisher` provides synchronous
    single-message publishing.
  - Decorator chain: `ContainingPublisherConnection` ->
    `FlowControlledPublisherConnection` (`MaxPendingBytesOption` /
    `MaxPendingMessagesOption` with `Block`, `Ignore`, or `Reject`) ->
    `BatchingPublisherConnection` -> `DefaultBatchSink` (unordered) **or**
    `OrderingKeyPublisherConnection` -> per-key `BatchingPublisherConnection` ->
    `SequentialBatchSink` when `MessageOrderingOption` is `true` (or
    `RejectsWithOrderingKey` when `false`).
  - **Ordering-Key Corking:** If a batch for an `ordering_key` fails with a
    permanent error, subsequent `Publish` calls for that key immediately fail
    until the caller invokes `Publisher::ResumePublishing(ordering_key)`.
- **Subscribing Pipeline (`Subscriber` -> `SubscriberConnection`):**
  - `Subscriber::Subscribe(callback)` and `ExactlyOnceSubscribe(callback)`
    return `future<Status>` representing the streaming pull session; **calling
    `.cancel()` on that returned `future<Status>` initiates graceful session
    shutdown** (`SessionShutdownManager`). Synchronous unary pull uses
    `Subscriber::Pull()`.
  - Pipeline: `StreamingSubscriptionBatchSource` (`AsyncStreamingPull` bidi
    stream) -> `SubscriptionLeaseManagement` (background `ModifyAckDeadline`
    timers up to `MaxDeadlineExtensionOption`) ->
    `SubscriptionConcurrencyControl` (`MaxConcurrencyOption` and
    per-`ordering_key` serial delivery via `SubscriptionMessageQueue`).
- **OpenTelemetry Message Tracing:** `internal/message_propagator.h` and
  `internal/tracing_*` propagate W3C trace context inside `googclient_*` message
  attributes to link producer, batch, and consumer spans.

## Build Sync and Running Tests

- Note that `google_cloud_cpp_pubsub.bzl` is generated by CMake from
  `pubsub/CMakeLists.txt` (alongside deprecated `pubsublite`); keep
  `# Do not sort: grpc++ must come last` intact in `pubsub/BUILD.bazel`.
- Unit tests: `bazelisk test --test_tag_filters=-integration-test`
  `//google/cloud/pubsub/...`
- Integration tests (`pubsub/integration_tests/`): Honor `PUBSUB_EMULATOR_HOST`
  when set.
